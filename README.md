# Currency Exchange

## О проекте

Currency Exchange — REST API для работы с валютами и обменными курсами.

Приложение позволяет:
- получать список валют;
- получать информацию о конкретной валюте;
- добавлять новые валюты;
- получать и добавлять обменные курсы;
- изменять существующие курсы;
- рассчитывать конвертацию суммы из одной валюты в другую.

Расчёт обмена поддерживает прямой курс, обратный курс и кросс-курс через USD.

## Стек технологий

- Java 21
- Jakarta Servlets
- JDBC
- SQLite
- Maven
- Jackson
- Apache Tomcat

Проект реализован без использования backend-фреймворков.

## REST API

| Метод | Endpoint | Описание |
|---|---|---|
| GET | `/currencies` | Получить список всех валют |
| GET | `/currency/{code}` | Получить валюту по коду |
| POST | `/currencies` | Добавить новую валюту |
| GET | `/exchangeRates` | Получить список всех обменных курсов |
| GET | `/exchangeRate/{pair}` | Получить курс валютной пары |
| POST | `/exchangeRates` | Добавить новый обменный курс |
| PATCH | `/exchangeRate/{pair}` | Изменить существующий курс |
| GET | `/exchange?from={code}&to={code}&amount={amount}` | Рассчитать конвертацию валют |

Поддерживаемые сценарии конвертации:
- прямой курс;
- обратный курс;
- кросс-курс через USD.


## База данных

Приложение использует SQLite.

Основные таблицы:

- `Currencies` — хранит валюты;
- `ExchangeRates` — хранит обменные курсы между валютами.

Для целостности данных используются:

- `UNIQUE` для кода валюты;
- `UNIQUE` для пары `BaseCurrencyId + TargetCurrencyId`;
- `FOREIGN KEY` между `ExchangeRates` и `Currencies`.

Проверка внешних ключей включается для каждого подключения через:

`PRAGMA foreign_keys = ON`.


## Архитектура

Приложение разделено на несколько слоёв:

- `servlet` — обработка HTTP-запросов и формирование HTTP-ответов;
- `service` — бизнес-логика конвертации валют;
- `dao` — работа с базой данных через JDBC;
- `model` — модели предметной области;
- `dto` — объекты REST-ответов;
- `exception` — пользовательские исключения;
- `filter` — общие настройки HTTP-ответов;
- `util` — вспомогательная инфраструктура приложения.


## Запуск локально

Для запуска приложения требуется:

- Java 21
- Apache Tomcat 10
- Maven

Шаги:

1. Клонировать репозиторий.
2. Собрать проект через Maven.
3. Развернуть сгенерированный WAR-файл в Tomcat.
4. Запустить Tomcat.

После запуска веб-интерфейс будет доступен по адресу:

`http://localhost:8080/currency-exchange/`

Пример обращения к REST API для получения списка валют:

`http://localhost:8080/currency-exchange/currencies`


## Сборка

Проект собирается в WAR-файл.

Через Maven:

`mvn clean package`

После успешной сборки файл будет находиться в:

`target/currency-exchange.war`


## Демонстрация

Приложение развёрнуто на VPS под управлением Ubuntu и доступно через Apache Tomcat.

**[Открыть Currency Exchange Service](http://153.76.160.170:8080/currency-exchange/)**

Через веб-интерфейс можно:

- просматривать доступные валюты;
- добавлять новые валюты;
- просматривать обменные курсы;
- добавлять новые валютные пары;
- изменять существующие обменные курсы;
- конвертировать суммы между валютами.

Приложение доступно публично и работает с общей базой данных SQLite. Изменения, внесённые посетителями, сохраняются в базе данных.

**Примечание:** это учебный проект. На данный момент используется HTTP без HTTPS.

Статические файлы интерфейса находятся в `src/main/webapp`.


## Конфигурация базы данных

Приложение использует SQLite.

Для указания пути к файлу базы данных поддерживается переменная окружения `APP_DB_PATH`.

На VPS база данных хранится отдельно от развёрнутого WAR-файла. Это позволяет сохранять данные при обновлении приложения и перезапуске Tomcat.

Если переменная `APP_DB_PATH` не задана, приложение использует базу данных из ресурсов проекта.
